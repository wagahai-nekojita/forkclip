# Security Policy

Forkclip handles clipboard history, local encrypted persistence, and Keychain-backed key storage. Please do not report security vulnerabilities through public GitHub Issues.

## Supported Scope

This repository is a portfolio source repository. Prebuilt app downloads are not provided at this stage, and the app is not currently signed or notarized for public distribution.

Security reports should focus on the source code, documented local storage behavior, encryption boundary, Keychain usage, and privacy-sensitive clipboard handling.

## Reporting A Vulnerability

Use the repository owner's GitHub profile contact path to report vulnerabilities privately. Include:

- affected source files or documentation;
- a concise description of the issue;
- reproduction steps that use synthetic clipboard data only;
- expected and actual behavior;
- any local environment details needed to understand the report.

Do not include real clipboard contents, real credentials, private files, personal screenshots, or sensitive logs in public Issues or PRs.

## Public Issues

Public Issues are appropriate for normal bugs, build problems, documentation corrections, and feature suggestions. They should not contain vulnerability details or sensitive reproduction data.
